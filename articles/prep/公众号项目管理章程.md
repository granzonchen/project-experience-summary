## 三、发文流水线（A+C 定版 v2）

```
① 备稿(md)：固定配方=一个真实事故+一个可复用配方+几条铁律+尾句；
   结构=钩子标题(≤64字)→摘要(≤120字)→编号小节→写在最后→互动句→蓝色尾句→系列落款→AI小字垫底
② 配图：gen_images.py；封面 900×383 + 内容图卡 900×H
③ 匿名化审查：公司/内网IP/域名/客户代号/他人账号 零出现
④ 建草稿：写 config.json → python build_draft.py config.json
   （传图→draft/add→draft/get 验证标题/摘要/图数；⚠️原创开关默认关）
⑤ 人草稿箱 4 步（约 5 分钟）：
   1️⃣ 勾「声明原创」+创作来源「内容由AI生成」（置顶关键动作）
   2️⃣ 逐张看图（豆腐块/数字粘连）
   3️⃣ 手机预览（图全/加粗在/特殊字符未变形/收口顺序对）
   4️⃣ 正文钩子的关键词回复已配置 → 点发表 → 新链接交 AI
⑥ 终检+登记：python verify_published.py <链接> --origin-baseline 1 --sections "..." --strong-min N
   → 选题池标发布 → 记忆/看板/PROGRESS → commit 双推
```

C 路线备份（辅助包人工粘贴+编辑器手动传图）：见各篇「发布辅助-NNN.md」，002 已验证。

### A1 「雕刻器」（半匹配）

```
你好，这是《SSD 上删掉的文件还能救吗？》配套的雕刻器完整脚本（约 180 行，纯 Python 标准库，无需装第三方包）：
👉 https://gitee.com/granzonchen/carve-tool

使用前记住三条红线：
① 只扫自己的盘——原始卷读取是取证级操作；
② 恢复输出写到另一块物理盘——往源盘写等于一边捞一边埋；
③ 记住 TRIM 窗口期——删除后越早扫越有戏；在 SSD 上它最大的用途，往往是出具"数据已物理销毁"的判决书。

仅限 Windows、管理员运行；脚本开头 VOL/OUT 两个常量改成你的盘符和输出目录。恢复出的 zip 先杀毒再打开。
工具没有立场，持刀的人有。
```
